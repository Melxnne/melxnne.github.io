# Melonne – Portfolio 2.0 🍉

Modernes, responsive Portfolio eines 17-j. Hobby-Entwicklers.  
Gebaut mit **Plain HTML, CSS & Vanilla JS** – keine Framework-Bloat.

## Features
- 🌗 Dark-/Light-Mode (mit System-Erkennung)  
- 📱 100 % responsiv (ab 240 px Breite)  
- ⚡️ Lighthouse 95+ (Performance, A11y, SEO)  
- ♿️ Keyboard- & Screenreader-optimiert  
- 🎞️ Mikro-Animationen (reduzierte-Bewegung-Respekt)  

## Verwendete Technologien
- CSS-Grid, Flexbox, Custom-Properties  
- Inter Variable Font  
- CSS `@media (prefers-color-scheme)`  
- ES-Module, localStorage, smooth-scroll
